Your website is hosted

Connect the database in your hosting account to unlock the admin dashboard. Enter credentials only in Render’s private Environment settings.

Account creation, activation and VPN connections stay disabled until setup is complete. This page does not collect passwords or database connection strings.

1. Get the database connections

Open Neon and select the top-private-plug project, then select Connect.

  1. Enable Connection pooling and copy the PostgreSQL connection string.
  2. In Render, save it under DATABASE_URL.
  3. In Neon, disable Connection pooling and copy the direct connection string.
  4. In Render, save that under TPP_MIGRATION_URL.

Use the database top_private_plug and role tpp_owner. Keep both connection strings private.

Open Neon console →

2. Choose your admin password

In Render, open top-private-plug-admin → Environment.

  1. Add TPP_BOOTSTRAP_PASSWORD.
  2. Enter a unique password of at least 14 characters.
  3. Choose Save, rebuild and deploy.
  4. Once deployment finishes, return here and sign in as admin using your password.

After your first successful login, remove TPP_BOOTSTRAP_PASSWORD from Render and redeploy. Your login stays stored in the database.

Open Render dashboard →

Create trial or paid access codes, set time and data allowances, manage accounts, and edit your connection profiles.
